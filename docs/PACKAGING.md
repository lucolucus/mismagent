# Packaging and maintenance

How mismAgent is packaged as one Claude Code plugin, how the same method is packaged for other
agent runtimes, and what keeps those packagings from drifting. For the method itself, see the
[README](../README.md).

## One plugin

`plugins/mismagent` is the **single source of truth**: four skills (`explore`, `specify`, `craft`,
`conventions`), one command (`build`, the conductor), four agents (`challenger`, `architect`,
`builder`, `reviewer`), the tool `mm.py` and two hooks. Its [README](../plugins/mismagent/README.md)
lists what each piece does. The superseded v0.26 flow is in `attic/v0.26/`, out of the plugin
registry on purpose.

## Other runtimes

`codex/` and `pi/` are **generated views** of the plugin — never edit them by hand. Both ship the
same pieces under `mismagent-` names (the skill space of both runtimes is flat), `mm.py` inside the
`mismagent-build` skill, and the plugin's README as the project's `AGENTS.md`.

What changes from Claude Code, on both:
- **Settings and conventions:** the project's `## mismagent` section lives in `AGENTS.md`, not
  `CLAUDE.md`, and the project's conventions skill in `.agents/skills/conventions/`, not
  `.claude/skills/conventions/`. The shipped `mm.py` reads those.
- **No hooks:** the two Claude Code hooks (agents never merge, tag or move state; never edit the
  human's files) are not shipped. The prompts state the rules and `mm check` verifies them.
- **No always-on mode:** `/loop` is Claude Code's; elsewhere the human calls the build again.

### Codex / OpenAI

Skills in `.agents/skills/` (`$mismagent-<name>`), agents as subagents in TOML in `.codex/agents/`
(the challenger, the reviewer and the architect at `model_reasoning_effort = "high"`; read-only
sandbox for an agent without Bash, Write or Edit). Regenerated by `tools/generate-codex.py`.

```
codex/install.sh /path/to/your/project
```

### pi

Skills in `.agents/skills/` (`/skill:mismagent-<name>`), the build also as a prompt template in
`.pi/prompts/` (`/mismagent-build`, so pi substitutes its argument), agent definitions in
`.pi/agents/` for pi's official `subagent` example extension, called with `agentScope: "both"`.
Regenerated by `tools/generate-pi.py`.

```
pi/install.sh /path/to/your/project
```

`pi/` is also a pi package: `pi/install.sh --package <dir>` writes an anchored copy for
`pi install <dir>` (skills and prompts; the agents and `AGENTS.md` still come from the project
install).

Re-running an installer upgrades in place: it replaces every `mismagent-` piece, so a retired one
goes too.

## Keeping the derived views aligned

`tools/derived.py` holds what both generators share; each generator adds its runtime's idioms.
Every run ends with a self-containment check: a Claude-only idiom (`CLAUDE.md`, `.claude/`,
`/mismagent:`, `/loop`, the plugin root), a call to a skill that is not shipped, a relative link or
an installed path that does not resolve fails the run with the list. A passage the derivation
depends on (the `/loop` paragraph, the paths `mm.py` reads) that moves in the source also fails
the run, with what to update.

`tools/tests/` generates each runtime, installs it into a fresh git project and runs its `mm.py`
there.

Two guards keep `codex/` and `pi/` in step with `plugins/`:

- **pre-commit hook**, versioned in `.githooks/`: a commit touching `plugins/` or a generator
  regenerates both trees and stages them in the same commit. Enable once per clone with
  `git config core.hooksPath .githooks`.
- **CI**, `.github/workflows/derived-views.yml`: runs `tools/tests/`; pull requests to master fail
  if a derived tree is stale; a push to master **self-heals** — the workflow regenerates and
  commits the difference, which also reverts any hand edit to `codex/` or `pi/`.

## Prompt budgets

`plugins/mismagent/tools/budgets.json` caps the words of every operative prompt file (skills,
agents, the command), their total, the skills' `references/` (separately) and every frontmatter
description (250 characters). `prompt_budget.py` checks it inside the tool tests; a new prompt
file needs a budget, and a cap only goes down.
