# mismAgent 0.5 — mechanisms as hypotheses

> **Layer 2 of 3.** Every mechanism the vision (`v0.5-vision.md`) may need, as a hypothesis: the
> problem it answers, the evidence so far, the experiment that confirms or refutes it, its status.
> A mechanism enters the core (`v0.5-core.md`) only when confirmed, or when an experiment needs it
> to be tested; it leaves when a removal experiment shows it does not earn its cost. One row each;
> no prose rules here.

Status: **core** (in the minimal core under test) · **later** (waits for its scenario) ·
**confirmed** · **refuted** · **kept** (proven on earlier runs, carried over).

## The measuring instrument (step 0, 2026-09-29)
The blind quality review is **noisy**: four reviews of the same code (E0 at R2) gave 3.14, 3.57,
3.57, 3.86 (mean 3.54, sd 0.29); on the design-passed code 3.57, 3.57, 3.71, 3.71 (mean 3.64).
Integer scores per dimension move by one point between reviews. So: every score is the **mean of
at least four reviews**; a difference under ~0.3 overall is not a result; deterministic metrics
(duplicated blocks, function and file length, import graph) are reported next to the scores; and
the primary measure of maintainability stays the cost and the defects of the next change.
