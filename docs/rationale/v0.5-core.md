# mismAgent 0.5 — the minimal core (arm B of S2)

> **Layer 3 of 3.** Exactly what S2 (`bench/scenarios/long-horizon/`) needs to test the main bet:
> the harness keeps the code maintainable over a long horizon at a few times the baseline's cost.
> It contains the rows of `v0.5-hypotheses.md` marked **core** and nothing else.
> Budgets: prompts ≤ 5,000 words in all (checked by `prompt_budget.py`); tool `mm` ≤ 500 lines.

## The flow for S2
1. **Intake + specify** (R0, then R1 with v2, R2 with v3, then each change request): the depth for
   S2 is fixed by the simulated user's policy — examples + slices, no storm, no UI exploration.
2. **Skeleton** (first slice of R0): the architect writes `ARCHITECTURE.md` with the layering, one
   owner per table and the error policy; wires the sensors
   (formatter/linter at zero warnings, size thresholds, suppression count) and the dependency lint
   into the gate; the builder builds the exemplary slice; the reviewer holds it to the highest bar.
3. **Slices**, in sequence: builder → reviewer → merge → if the slice left convention proposals
   (always after the model slice), `/mismagent:conventions` with the human before the next one; two rework rounds at most, then the architect
   decides by the standard.
4. **Release**: the reviewer runs the app; a cheap blind score on the review table; if a dimension is
   below 4, or sensors or notes signal, the **design pass** runs before the next request.
5. **Guard**: a hook refuses agents' edits to the requirements and `examples.md`; `mm check --base`
   refuses them in the diff, and modified acceptance tests of other examples in a feature slice.

## `mm` — the tool (≤ 500 lines, stdlib)
- `mm status` — slices per folder, examples ↔ acceptance tests, last suite result (JUnit XML).
- `mm next` — the next slice (a queued refactoring first) or why there is none.
- `mm start` / `mm land` / `mm tag` — the only state writes (see `v0.5-build-plan.md` §3).
- `mm check` — files well formed, sensors' suppression count, the files the conventions skill cites
  exist. No word cap on `.mismagent/`: agents read the map, the skill and the tail of `progress.md`;
  what lasts is distilled into the skill, never compacted away (M14).

## Not in the core (waits for its scenario)
Event storming, example mapping, probing, UI exploration, advocates, the archaeology pass,
characterization tests, duplication and complexity sensors, parallelism, the board.

## Done for the core
The prompts and `mm` within budget; the unit tests of `mm` green; a dry run of the flow on a toy
request; then S2 arm B.
