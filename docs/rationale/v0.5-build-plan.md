## 3. `tools/mm.py` (stdlib, ≤ 500 lines) + tests — owns ALL the git and all the counting
*(revised after the plan review: the slice lifecycle is the riskiest part; a prompt must not carry it.)*
**No branches.** Slices are built one at a time **on main**; `mm start` records the base SHA; the
reviewer reviews `base..HEAD`; a REWORK adds commits; nothing moves to done without a PASS at HEAD
and a green gate.

**Project config** — in the project's `CLAUDE.md`, section `## mismagent`, lines `- key: value`:
`test` (whole suite, exit 0 = green) · `lint` (format check + linter, exit 0 = clean) · `smoke`
(starts the app headless, exercises one use case, exits — never a blocking main loop) ·
`max_file_lines` (default 400) · `suppressions` (allowed count, default 0).

**Files it reads** (line-based parsing):
- `.mismagent/examples.md` — table `| id | given | when | then | rule | req | release |`; ids `EX-<n>`.
- `.mismagent/slices/{todo,doing,done}/NN-name.md` — header lines `Kind: model|feature|refactor`,
  `Release: <token>` (R0, R3, CR1… any token), `Examples: EX-1, EX-2` (may be empty), `Base: <sha>`
  (written by `mm start`); sections `## Question` and `## Answer`.
- `.mismagent/reviews/<slice-stem>-<k>.md` and `.mismagent/reviews/<release>-<k>.md` — lines
  `VERDICT: …`, `SHA: <reviewed HEAD>`, `SCORES: simple=4 …`.
- `.mismagent/design-notes.md` — items = lines starting `- `.
- `tests/acceptance/**` — example ids by the marker `EX-<n>` (never `E501`-like codes).

**Commands:**
- `mm status [--json]` — slices per state and per release; examples without an acceptance test;
  acceptance markers naming unknown examples; notes count.
- `mm next [--json]` — exactly one action, first match wins:
  1. a slice in doing: Question without Answer → `blocked`; review at HEAD = PASS → `land`; review
     at HEAD = REWORK → `rework k` (k = REWORK count, ≤ 2) or `escalate` (3rd); no review at HEAD →
     `review` if HEAD ≠ Base and the tree is clean, `build` if HEAD = Base, `resume` if dirty.
  2. the first release whose slices are all done and not tagged: no release review at HEAD →
     `release-review`; HEALTHY → `confirm` (a human act); DESIGN-PASS → `design-pass` (after two
     design passes for that release → `confirm`, with the reason).
  3. design notes > 5 and no refactor slice in todo → `design-pass notes`.
  4. a slice in todo (refactor first, then by number) → `start`.
  5. `idle` (the next release needs specify) with the reason.
- `mm start <slice>` — clean tree, no slice in doing; `git mv` todo→doing, writes `Base:`, commits.
- `mm land <slice>` — PASS at HEAD and `mm gate` green; `git mv` doing→done, commits.
- `mm gate` — runs `test` and `lint` from the config, then `mm check`; exit ≠ 0 if anything is red.
- `mm tag <RN>` — all its slices done, gate green; `git tag -a RN`. Called by the conductor only when
  the human's confirmation is in its arguments.
- `mm check [--base <ref>]` — examples well formed, ids unique; slice headers valid; each example of a
  done slice has an acceptance marker; suppression markers (`noqa`, `pylint: disable`,
  `eslint-disable`, `@SuppressWarnings`, `type: ignore`, `nolint`) ≤ `suppressions`; tracked source
  files ≤ `max_file_lines`; with `--base`: acceptance files **modified** since the ref
  (`--diff-filter=M`), or any change to `REQUISITI*`, `requirements*`, `.mismagent/examples.md` →
  error; a file cited by `.claude/skills/conventions/**.md` missing → error (no word cap on
  `.mismagent/`, see M14); with `--base`, a change to the conventions skill → error (the human's file). Exit 1 on an error.

## 4. Hooks (a courtesy; `mm check --base` is the real guard)
- `guard-git.py`: agents builder, reviewer, architect (suffix match on `agent_type`); denied: merge,
  push, rebase, reset --hard, checkout, switch, branch -d/-D, stash, tag, `git mv` under
  `.mismagent/slices/`. Commits are allowed.
- `guard-human.py` (new, PreToolUse on Edit|Write|MultiEdit|NotebookEdit): the same agents may not
  write `REQUISITI*.md`, `requirements*.md`, `.mismagent/examples.md`. Tests for both.

## 5. The flow — one action per firing of `/mismagent:build [--confirm RN]`
- No `ARCHITECTURE.md` → architect (skeleton): `ARCHITECTURE.md`, the sensors and `## mismagent` in
  `CLAUDE.md`, the `smoke` entry point; it marks the **first real slice** (the smallest end-to-end
  example) `Kind: model` — the model the rest copies.
- Else `mm next`, then: `start`/`build`/`resume`/`rework` → builder · `review` → reviewer (slice) ·
  `land` → `mm land` · `escalate` → architect decides · `blocked` → frame the doubt; local → answer
  it in `## Answer` and record it; important → print `NEEDS-HUMAN: <slice file>` and stop ·
  `release-review` → a **fresh** reviewer (release mode) that never reads the slice reviews ·
  `design-pass` → architect · `confirm` → with `--confirm RN` in the arguments `mm tag RN`, else
  print `NEEDS-HUMAN: confirm RN` and stop · `idle` → report and stop.
- **One action per firing**; the runner loops. No long conductor session.
- Human answers arrive on disk: the `## Answer` section of a slice, or `--confirm RN`.

## 6. Bench for arm B
